# 곡 설명 — 예시곡.wav

**한 줄 느낌(추정):** 어둡고 진지한 느낌의 느리고 차분한 곡, 소리는 잔잔한 편, 낮은 소리가 많아 묵직함
- 길이 0:40.0 / 조 D 마이너(라단조) — 확신 낮음 / 빠르기 약 60 BPM (반이나 두 배일 수 있음)
- 반복되는 부분: B(2번), C(2번) — 그중 C가 같은 가사·멜로디로 반복되고 세서 후렴으로 봤습니다
- 가사 받아쓰기 모델이 없어 노래가 있는지는 소리 세기로만 짐작했습니다.
- **음악 AI가 들은 장르:** 일렉트로닉·Chiptune (16%), 일렉트로닉·Chillwave (14%), 일렉트로닉·Synth-pop (11%)
- **음악 AI가 들은 분위기:** 느린 (25%), 어두운 (12%), 멜로디가 좋은 (11%), 편안한 (7%)
- **음악 AI가 들은 악기(곡 전체):** 신시사이저 (59%), 드럼 머신 (19%), 피아노 (17%), 샘플러 (15%), 드럼 (14%), 일렉 기타 (14%)
- 퍼센트는 AI가 '들린다'고 믿는 정도입니다. 30% 넘으면 꽤 확실, 15% 안팎은 '아마'.

## 들은 대로 말하면

- **0:00.0** 전주 — 묵직한 저음이 깔리고, 신시사이저·피아노 소리
- **0:08.5** 확 커지며 노래 B — 드럼이 깔리고
- **0:15.5** 확 커지며 후렴 1번째 — 드럼이 깔리고, 샘플러 소리가 새로 들림
- **0:24.5** 확 작아지며 노래 B (2번째 반복) — 드럼이 깔리고
- **0:31.5** 살짝 커지며 후렴 2번째 — 드럼이 깔리고, 샘플러 소리가 새로 들림

※ 구간 이름·분위기·악기는 소리 특징으로 짐작한 것입니다. 닮은꼴 글자가 같으면 비슷한 멜로디·화음의 반복입니다.
※ 드럼·저음 칸은 소리 특징으로, '들리는 악기' 칸은 음악 AI(Essentia, 비상업용 모델)가 들은 것입니다. 악기 AI는 반주가 있는 곡으로 배워서 목소리만 있는 파일에서는 믿기 어렵습니다.
